# BENCH-001 source-blind execution readiness

This freezes the approved transcription of **IA-001-BENCH-v1**, not new benchmark
results. Sources, hidden fidelity keys, provider verification and live execution
authority are absent. Owner verdict is PENDING. No architecture is promoted or ranked.

S preserves original prose. A is direct explanation; B plans then explains. C0 reuses
current monolithic extraction and canonical pipeline/routing. C+ reuses frozen Candidate
B v2 inventory/structure/evidence admission, then composes from BOTH the entire admitted
semantic store (including claim-only content) and the original source. No atomizer/judge,
hand-crafted product fixtures, topology repair or source-specific routing is introduced.

Prompts and strict schemas are frozen in this directory. Dynamic C+ enum identities
are mechanical instantiations of frozen native factories, not prompt/schema tuning.
The exact shared task is in every explanation/composition prompt. C0 keeps its actual
extraction prompt, not a new teaching prompt. It cannot silently gain claim-focus routing
or an unavailable comparison renderer. Its compatible renderer uses unchanged native
plan/diagram function bodies and geometry, with a minimal host. The full product
navigation workspace is not evaluated by that host. Native styling/focus-menu differences
remain explicit confounders, not hidden equivalence claims.
The native C0 prompt permits INFERRED outside-source knowledge; that limitation is
retained, not repaired. Independent fidelity review must assess unsupported content
and material failures in C0 as in every other arm.

The common-model request adapter is isolated under `tools/`; no production adapter
changed. It changes request plumbing only: model, reasoning high, store false, budget
allocation and timeout. Local SDK 2.54.0 accepts those request fields; remote model/support
and model seed support remain UNVERIFIED. OpenAI Docs online verification was deliberately
not performed because the owner forbids network/provider calls under this packet.

Input accounting is fail-closed: a request-bound certified exact token counter is required
before transmission. No byte heuristic is represented as a proven model tokenizer. A
later execution packet must establish that counter identity, provider support and a
zero-retry cancellation-respecting transport. Actual response usage and durations are
checked too; missing usage, counter overruns, incomplete output or timeout fail the cell
and prohibit later stages/retries. Actual provider/model construction is not exposed by
the readiness CLI. Synthetic test doubles are not model calls or benchmark outputs.

Source anchors certify exact source recovery, not entailment. Every visible generated
block, label/caption/table cell needs a unique quote. Two qualified independent humans
freeze hidden obligations/questions before generation; a third adjudicates disagreements.
Independent fidelity judgment and learner preference remain separate from model metadata.

All 25 source/arm cells remain in the denominator, including failures. The 40-call ledger
is a conditional ceiling, not an obligation or permission to fill every slot. Metrics and
identity keys stay with the independent custodian until learner verdicts lock; labels are
not assigned now. Counterbalancing and its public seed are frozen before outputs; a
future independent custodian must seal a private 256-bit secret and freeze its commitment
before source exposure. The public seed alone cannot seal label/order identity.
