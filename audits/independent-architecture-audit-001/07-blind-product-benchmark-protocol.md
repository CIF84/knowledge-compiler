# 07 — Future blind product benchmark protocol (design only)

No source was selected/retrieved, no output generated and no benchmark executed.
This protocol creates no live-call authority. The owner anti-anchoring amendment also
withholds the contract's predefined arm menu: the independent auditor must derive and
freeze all competing approaches before output inspection. A custodian must not supply
team architectures disguised as “baseline arms” in the initial briefing.

## Source rules, frozen before future retrieval

Five English educational/explanatory passages, one each with a dominant mechanism,
process, comparison, abstract theory and interconnected-system knowledge shape;
five distinct domains. “Dominant” is a selection stratum, not a claim that the source
fits one exclusive type. Prefer stable public institutional educational publishers,
dated/revision-addressable documents, or archival public editions. No authentication,
private data, personalized/high-stakes advice or figure-dependent meaning.

Target 400–900 words per passage, retaining whole explanatory units; no source longer
than 1,200 words including necessary context. If no eligible passage is found for a
stratum, record failure and seek new authority rather than trim away qualifications.
An independent selector uses publisher/document order and first eligible contiguous
explanatory passage, not perceived difficulty or expected candidate success. Freeze the
selector identity, ordered candidate list and every rejection rule before generation.

Exclude all previously used source documents/revisions, paraphrases or excerpts from
the repository's golden fixtures, Wikipedia quantum work, economics/software controls,
042/045 nine-source corpus and 060–068 derivatives. Recovered electromagnetism is excluded
as a benchmark source. Search the frozen corpus locally for exact/normalized hashes,
URLs/titles, substantive text overlap and near-duplicate topics; record uncertain overlap
for independent adjudication before admission. “Unseen” means not in this experimental
corpus; absence from model pretraining cannot be established and must not be claimed.

A later authorized retrieval packet records original response bytes, canonical URL,
publisher/revision/time, document/passsage hashes, full bounded text, selection offsets,
normalization and all exclusions. Freeze all five and sign the manifest before any
candidate receives source text. No replacement after observing an output or failure.

## Arms and execution frozen by the independent auditor

The auditor independently derives competing approaches and the simplest meaningful
product-thesis comparator, without being handed current-team candidates. Before any
benchmark result, freeze the chosen executable versions, prompts, models, settings,
resolution rules, budgets, storage/retry policies, source scopes and admission criteria.
The objective is preserved meaning/qualification and easier understanding/retrieval,
not maximizing schema objects, diagrams or word-count reduction.

No manual rescue, source-specific prompt adaptation, output rewriting, hidden retry,
substitution of a hand-built experimental path for a failing executable path, or extra
judge without new authority. Inability to produce a complete learner output is a result.
Save every response/failure plus the exact rendered output and raw input identities.
Implementation effort for any new arm is measured separately, not assumed free.

## Blind learner review

An independent custodian assigns opaque labels and records a pre-frozen randomization
seed/order, counterbalancing output order across sources. Keep the identity key and
system metrics sealed until human verdicts are locked. Equalize reading environment,
source availability, device and review instructions; preserve meaningful format differences
but remove author/model/architecture labels, compiler/debug metadata and identifying UI chrome.
Record any unavoidable unblinding. The owner must not be the arm selector/identity keeper.

For each source, review fastest path to understanding, clearest mental model, information
compression, important nuance preservation, later recall usefulness, relationship visibility,
unnecessary overhead, preference for first learning and preference for later review. Use
paired ordinal ratings plus direct reasons and confidence; allow ties, “neither”, and
insufficient evidence. Capture reading time and fixed comprehension questions only if
their content/scoring is independently frozen before generation. A recall impression is
not a measured delayed-recall score; a later recall trial needs its own frozen interval/test.

Baseline source prose must remain directly available as a recovery/control record. A
single-owner five-source review is formative evidence, not population-level causality.
Pre-register missing-output scoring so failed arms cannot disappear from the denominator.

## Separately sealed system evidence

Record actual calls/transmissions, model/token usage (including failures), cache fields,
latency and elapsed time, retries/repairs/manual interventions, provenance/recovery checks,
admission failures and implementation complexity. Record dollar costs only when supported
by receipts or separately frozen price evidence. Do not reveal these metrics during
learner review. Keep semantic fidelity evaluation independent from preference ratings.

Only a later owner-approved execution packet can activate this design. Architecture
diagnosis/recommendation must already be independently frozen before current-team hypotheses
are revealed; benchmark revisions after that reveal require a new explicit version and
must not be represented as the original unanchored independent design.
